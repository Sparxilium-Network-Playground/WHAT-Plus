# 管理客戶端使用指南

> 最後修改：2026-11-13

管理客戶端（`whatplus-client.exe`，只支援 Windows）負責日常設定：報告要發到哪些 Discord 頻道、什麼時候發、內容有哪些，以及哪些電腦可以上傳用量。介面提供繁體中文與 English，這份說明使用繁體中文介面的名稱，括號內是英文介面的名稱。

取得與建置方式見[安裝說明](INSTALL.md#4-安裝管理客戶端)。

## 畫面配置

左側是導覽列，最上方顯示目前的連線狀態（未連線，或連線的身分）。除了**連線**與**偏好設定**，其他頁面都要先連上伺服器才能使用。

| 區塊 | 頁面 | 用途 |
|---|---|---|
| | 連線（Connection） | 連上伺服器 |
| | 伺服器狀態（Server status） | 查看伺服器的運作情況 |
| 報告（Reports） | 立即發送（Send now） | 預覽或馬上發送一份報告 |
| | 排程（Schedules） | 每日、每週、每月自動發送 |
| | Discord 頻道（Discord channels） | 報告要發到哪些頻道 |
| 來源（Sources） | 來源機器（Machines） | 哪些電腦可以上傳用量 |
| | 偏好設定（Preferences） | 介面語言與主題 |

執行中的操作會在導覽列下方顯示「處理中…」。操作結果顯示在頁面下方。

## 連線

### 第一次連線

1. **伺服器**區塊：
   - **位址**：伺服器的區網 IP 或主機名稱，例如 `192.168.1.10`。
   - **Port**：預設 `33445`。
2. **管理金鑰**區塊：
   - **.ssh 中的金鑰**：列出 `%USERPROFILE%\.ssh` 裡的 Ed25519 私鑰，選擇安裝時產生的 `whatplus_admin`。
   - 金鑰放在其他位置時，選清單第一項「（其他檔案）」，再按「瀏覽…」選擇**私鑰檔**。
   - **Passphrase**：金鑰有設定 passphrase 時才需要填，不會被儲存。
3. 按「連線」。
4. 第一次連到這台伺服器時，會顯示「第一次連線到這台伺服器」與伺服器指紋。與伺服器設定精靈或[伺服器設定畫面](SERVER-TUI.md)上顯示的指紋**完全相同**，才按「信任並連線」。

連線成功後，指紋會顯示在**已記住的指紋**，之後每次連線都會比對。設定（位址、金鑰路徑、指紋、語言）存在 `%APPDATA%\WHATPlus\config\client.json`，下次開啟會自動帶入。

### 連線失敗時

| 訊息 | 處理方式 |
|---|---|
| 伺服器拒絕這把金鑰 | 這把金鑰還沒在伺服器註冊成 admin，或被停用了。用伺服器的設定精靈或設定畫面加入 |
| 連線被關閉、connection reset | 你的 IP 不在伺服器白名單內，或伺服器還沒有 admin 金鑰。見[常見問題](INSTALL.md#常見問題) |
| 伺服器指紋改變 | 確認是自己重新安裝了伺服器，才按「忘記」清除已記住的指紋，再重新連線並比對。否則**不要連線** |
| 這把金鑰有 passphrase | 在 **Passphrase** 欄位輸入後再按「連線」 |

閒置一段時間後連線可能被中斷，下一個操作會自動重新連線一次。要切換伺服器或金鑰，先按「中斷連線」。

## 伺服器狀態

按「重新整理」取得最新狀態：

| 項目 | 說明 |
|---|---|
| 伺服器版本 | 伺服器程式的版本 |
| 時區 | 排程與報告期間使用的時區 |
| 伺服器指紋 | 可與連線頁「已記住的指紋」對照 |
| Discord | Bot 的連線狀態。顯示 `ERROR` 時 Token 有問題，要在伺服器上重新執行設定精靈 |
| 來源機器 | 已註冊的來源端數量 |
| 用量紀錄 | 伺服器上的紀錄總數 |
| IP 白名單 | 允許連線的位址範圍（在伺服器上修改） |
| 最近一次報告／最近結果 | 最後一次發送的時間與結果 |

## Discord 頻道

報告要發到的頻道。每個頻道各自選擇報告語言。

### 新增頻道

1. 按「載入 Server 與頻道」。只會列出 Bot 已經加入的 Discord Server。
2. 選擇 **Discord Server** 與**頻道**。Bot 在頻道需要 View Channels 與 Send Messages 權限。
3. **名稱**：在客戶端顯示用的名稱。留空時使用「#頻道名稱」。
4. **報告語言**：English 或繁體中文。
5. 按「新增」。

新增後建議先按「測試」，確認頻道收到測試訊息。

### 管理既有頻道

| 按鈕 | 作用 |
|---|---|
| 測試 | 送一則測試訊息到這個頻道 |
| 停用／啟用 | 暫停或恢復發送到這個頻道，設定會保留 |
| 刪除 | 刪除頻道。還有排程使用這個頻道時無法刪除，畫面會顯示是哪個排程，請先在那個排程取消勾選這個頻道 |

## 排程

自動發送的報告。可以建立多個排程，例如每天早上發到 `#daily`、每週一發到 `#team`。

### 新增或編輯排程

按「新增排程」，或點清單中的排程進行編輯：

| 欄位 | 說明 |
|---|---|
| 名稱 | 排程的名稱 |
| 週期 | **每天**：送前一天的用量。**每週**：選擇星期幾，送前 7 天。**每月**：每月 1 號送上個月 |
| 時間 | 幾點幾分發送，以**伺服器時區**為準 |
| 內容 | 報告要包含哪些項目，見下方「報告內容」 |
| 頻道 | 要發到哪些頻道，至少選一個 |
| 啟用 | 取消勾選可以暫停這個排程 |

按「儲存」完成。清單會顯示每個排程最近一次執行的時間與結果。

- 修改排程後，從修改的時間點重新計算，不會補送修改前錯過的報告。
- 伺服器停機時錯過的報告，6 小時內恢復的會補送，超過 6 小時的不會補送。

## 立即發送

不必等排程，馬上產生一份報告。適合第一次設定時確認效果。

1. **期間**：今天、昨天、最近 7 天、本月、上個月。
2. **內容**：要包含的項目。
3. **Discord 頻道**：勾選要發到哪些頻道（清單是空的，或剛新增了頻道時，按「重新載入頻道」）。
4. 按「預覽」可以先在畫面上看到報告內容（選擇**預覽語言**）；確認後按「發送」。

每個頻道會收到它自己設定的語言的報告。報告的資料來自各來源端**到目前為止上傳的紀錄**，來源端預設每 10 分鐘上傳一次，所以「今天」的數字可能還不是最新的。

## 報告內容

| 選項 | 內容 |
|---|---|
| 總費用與 token | 期間總費用、token、請求數 |
| 各工具 | Claude Code／Codex／Antigravity 分別的費用 |
| 各模型 | 費用最高的 8 個模型，其餘併為「其他」 |
| 各機器 | 每台來源電腦的費用（名稱就是來源機器的名稱） |
| 專案排行 | 費用最高的 5 個專案（機器 / 專案） |
| Token 明細 | 輸入、輸出、快取寫入、快取讀取 |

費用依公開 API 價格估算，**不是**實際帳單。報告中的文字（例如專案名稱）會經過處理，`@everyone` 之類的內容不會觸發提及。

## 來源機器

哪些電腦可以上傳用量。清單顯示每把金鑰的角色、名稱、紀錄數、最後連線時間，以及允許的 IP。

### 新增來源機器

1. 在來源端電腦執行設定精靈，第 4 步會顯示一行公鑰（`ssh-ed25519 AAAA... 電腦名稱`）。
2. 在這裡填入：
   - **名稱**：這台電腦的名稱，會出現在報告的「各機器」。
   - **公鑰**：貼上整行公鑰。
   - **允許的 IP 範圍**：選填，限制這台電腦只能從哪些位址連線，例如 `192.168.1.20/32`。留空表示伺服器白名單內的任何位址都可以。
3. 按「新增」，再回到來源端的設定精靈繼續。

### 管理來源機器

| 按鈕 | 作用 |
|---|---|
| 停用／啟用 | 停用後這台電腦無法上傳，已上傳的紀錄保留 |
| 刪除 | 刪除這台電腦，**連同它上傳的所有紀錄**，無法復原 |

admin 金鑰（管理客戶端用的金鑰）也會列在清單中，但不能在這裡修改或刪除，只能在[伺服器設定畫面](SERVER-TUI.md)管理。這是為了避免管理客戶端被盜用時，對方再加入新的 admin 金鑰。

## 偏好設定

- **語言**：繁體中文或 English，立即切換。
- **主題**：跟隨系統、淺色或深色。
- **關於**：版本與授權資訊。
